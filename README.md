# NoteFlow — גרסה 1.4

אפליקציית PWA ללימוד קריאת תווים בפסנתר. מותאמת לאייפון, עובדת אופליין, וכל הנתונים נשמרים מקומית במכשיר.

## מה יש בגרסה הזו
- **מסלול בארבעה מסלולים מקבילים:** מפתח סול, מפתח פה, שני המפתחות יחד, ודיאז ובמול. יש 11 שלבים, מ־C4–G4 ועד A3–C6 / C2–E4. אף שלב לא נעול.
- **דיאז ובמול:** מעל כפתורי C–B יש שורת כפתורים במיקום הקלידים השחורים (C♯/D♭ …). כפתור שחור מקבל את שני הכתיבים של אותו קליד, וטעות בסימן ♯/♭ נמדדת כסוג טעות נפרד.
- **שתי מיומנויות שנמדדות בנפרד:** זיהוי שם התו (כפתורי C–B) ומציאת התו על המקלדת (כולל אוקטבה מדויקת).
- **תרגול:** משוב מיידי, שלושה רמזים מדורגים שלא חושפים את שם התו, השמעת התו, עצירה והמשך, והסבר על כל טעות לפי סוג הטעות.
- **מבחן:** בלי רמזים ובלי משוב. התוצאות והניתוח מוצגים רק בסוף.
- **מנוע אדפטיבי:**
  - תווים חלשים, איטיים, חדשים או שהגיע מועד החזרה עליהם מופיעים יותר.
  - תווים שכבר נשלטו ממשיכים להופיע.
  - חזרה מרווחת במרווחים של 1, 3, 7, 16, 35 ו־80 ימים.
  - הגבלת הזמן מתקצרת רק לתווים שכבר יציבים.
  - אחרי שתי טעויות ברצף מגיעה שאלה קלה, וכל אימון מסתיים בתו קל.
- **ספי שליטה (ניתנים לכוונון):**
  - "מוכן למבחן": לפחות 5 ניסיונות לכל תו, ב־80% דיוק ומעלה.
  - "עבר": 90% דיוק במבחן וזמן תגובה חציוני של עד 2 שניות.
  - "שולט": מעבר נוסף של המבחן אחרי יום לפחות.
- **מוטיבציה:**
  - יעד שבועי בלי רצפים ובלי עונש על יום שהוחמץ.
  - אתגר יומי זהה לאורך כל היום.
  - שיאים אישיים, ו־12 הישגים שמתגמלים רק שיפור אמיתי.
  - מפת שטף שבה התווים מתמלאים בזהב לפי שליטה.
- **סטטיסטיקות:**
  - סינון לפי תקופה, מיומנות, מפתח וטווח.
  - מגמות דיוק ומהירות לאורך זמן.
  - טבלה לפי תו, וחלוקה לפי סוגי טעויות.
- **נתונים:** ייצוא וייבוא של גיבוי, בקשה מהדפדפן לאחסון קבוע, ואיפוס עם אישור מפורש.

## חדש בגרסה 1.1
- **שיעור קצר לפני כל שלב:** רעיון אחד, דוגמה על החמשה והשמעה. מופיע בפעם הראשונה, ואפשר לפתוח שוב מהמסלול ("הסבר").
- **מנגינות:** קריאת רצפים ב־4/4 עם הצצה קדימה (תו, +1, +3, תיבה, שורה). שבע מנגינות ברשות הציבור עם מקור ורישיון (Ode to Joy, Twinkle, Mary Had a Little Lamb, Hot Cross Buns, Au clair de la lune, Jingle Bells, London Bridge), ומנגינות מקוריות שנוצרות מחדש. מבחני שליטה משתמשים רק במקוריות, כדי למדוד קריאה ולא זיכרון. בסוף: השמעה בקצב או תו כל 300ms.
- **מקצב:** שלוש רמות (רבעים/חצאים/שלמים → שמיניות ושתיקות → נקודות ושש־עשריות), ספירה מקדימה ומטרונום על שעון האודיו, מדידת הקשות: בזמן, מוקדם/מאוחר, החמצות, הקשות עודפות והקשות בשתיקה. כיול השהיה בהגדרות.
- **עצירה ושחזור:** יציאה מהאפליקציה עוצרת את השעון. כל תשובה נשמרת, ואחרי רענון מוצע להמשיך מאותו מקום.
- **תרגול הטעויות:** כפתור במסך התוצאות שבונה תרגול רק מהתווים שהיו בהם טעויות.
- לחיצה ידנית על "השמעה" נחשבת לעזרה (כמו רמז). ההשמעה האוטומטית נשארת כברירת מחדל.

## חדש בגרסה 1.2
- **זהות חזותית "הכלי עצמו":** הובנה (שחור) לפעולות, שנהב למשטחים, פליז להתקדמות ולתו הנוכחי, לבד אדום כקו קישוט יחיד. אייקון חדש, ניווט תחתון (בית · מסלול · תרגול · התקדמות).
- **היכרות ראשונה:** שם, בדיקת צליל (עם הנחיות למתג השקט באייפון) ומה נלמד.
- **בית רגוע:** האימון המומלץ במרכז, ואחריו רק מה שממתין (המשך, מבחן מוכן, חזרה, בדיקה שבועית) והישג אחרון. שאר הנתונים עברו ל"התקדמות".
- **אימון יומי של 10 דקות:** ארבעה בלוקים קצובים בזמן, לפי אופי שנבחר: "להכיר משהו חדש", "לחזק את המוכר" או "פשוט לנגן". נגמר בסיום מוזיקלי — משפט קצר מהתווים שתורגלו.
- **תרגילים חדשים:** "שומעים ומוצאים" (צליל נשמע, בוחרים את מקומו על החמשה); פסנתר חופשי שמציג כל צליל על החמשה, עם הקלטה, השמעה ושמירה כמנגינה לקריאה.
- **ספר שירים ומנגינה שגדלה:** Ode to Joy בגרסאות עשירות יותר (שמות → מקלדת → מקצב); המנגינות שלך.
- **סדנת טעויות:** בלבולים שחוזרים על עצמם (למשל תו שנקרא במפתח הלא נכון) ואימון ממוקד לכל אחד.
- **"כך הקשת":** השמעה של ההקשות שלך מול הדוגמה בתרגילי מקצב.
- **סיכום שבועי, בדיקת קריאה שבועית** על משפט חדש באותם תנאים, ו**אתגר זוגי** יומי עם שורת שיתוף.
- **תוצאות בהיררכיה:** קודם מה הצליח, אחר כך נקודת שיפור אחת עם תרגול מתאים, והניתוח המלא מקופל. מקלדת תוצאות צבועה לפי דיוק, וחגיגה במעבר מבחן שליטה.
- **מסלול כמסע ומפת שטף כמקלדת** במסך ההתקדמות.
- **נוחות קריאה:** תווים גדולים, ניגודיות גבוהה, צמצום אנימציות. מעברים רכים בין תווים, סמן פעמה ברור, בלי קפיצות פריסה.

## חדש בגרסה 1.3
- **מקלדת אמיתית:** זיהוי צלילים דרך המיקרופון (YIN, במכשיר בלבד) או כבל MIDI, בכל תרגילי המקלדת, המנגינות, שתי הידיים והנגינה עם ליווי. מסך בדיקה חי. האפליקציה מתעלמת מהצלילים שהיא עצמה משמיעה.
- **ידיים ואצבעות:** מספרי אצבעות במיקום C לשתי הידיים, תרגיל "איזו אצבע", ומספרים מעל מנגינות שנכנסות בחמש אצבעות.
- **שתי ידיים:** חמשה כפולה עם סוגר; זוגות תווים ומנגינה מעל בס; Ode to Joy בשתי ידיים בספר השירים.
- **סימני סולם:** G, F, D ו־B♭ מז׳ור; כללי ♯/♭/♮ עד סוף התיבה.
- **קריאה חכמה:** תווי עוגן, "סופרים מהעוגן", ומרווחים (צעד, דילוג, קוורטה, קווינטה).
- **סימנים מוזיקליים:** מילון של 20 סימנים עם דוגמאות שמע, וחידון.
- **נגינה עם ליווי:** הליווי מחכה לך, או בקצב עם ספירה מקדימה; ליווי בס ואקורדים לכל השירים ולמנגינות מקוריות.
- **לופר בפסנתר החופשי:** עד ארבע רצועות שמוקלטות מעל לופ של 1, 2 או 4 תיבות, עם ספירה מקדימה, מטרונום, יישור לחצי פעמה, השתקה ומחיקה לכל רצועה.
- **אייפד:** פריסה רחבה, ובמסך לרוחב — התווים בצד אחד והתשובות בצד השני.
- **תזכורת יומית** ליומן, **כרטיס התקדמות חודשי** כתמונה, ו**מצב ערב** (צבעים חמים וצליל רך, גם אוטומטית מ־20:00).

## חדש בגרסה 1.4 — עיצוב חדש
- **"על החמשה":** חמשת קווי החמשה עוברים מתחת לכל כותרת ומתחת לברכה במסך הבית; המסלול מוצג כתווים שמטפסים על החמשה. לבן, כחול שמיים וכחול עמוק, ואלמוג לצעד הבא בלבד. גופן הכותרות: Secular One.
- **צבע לכל תו:** C ורוד־אדום, D כתום, E זעפרן, F ירוק, G טורקיז, A כחול, B סגול — בכפתורי השמות, בנקודות ההתקדמות, בתו הנכון על החמשה ובמקלדת הבית (נקודה מתחת לקליד).
- **הפסנתר נשאר שחור־לבן** בכל מקום; סימון נכון/טעות הוא נקודה על הקליד.
- **מצב כהה** בכחול לילה, ו**מצב ערב** כבמת קונצרט: קטיפה, וילון, חמשה בשנהב וזהב.
- אייקון חדש, כרטיס חודשי חדש ומסך פתיחה חדש.

## פיתוח
```
npm install
npm run dev        # שרת פיתוח
npm test           # 72 בדיקות: מודל מוזיקה, הערכה, רמזים, מנוע אדפטיבי, ספי שליטה
npm run build      # PWA לתיקייה dist
npm run build:preview  # קובץ HTML יחיד (בלי Service Worker) לתצוגה מקדימה
```

## פרסום ב־GitHub Pages
1. צור ריפו חדש ב־GitHub, ודחוף אליו את התיקייה הזו לענף `main`.
2. בריפו: Settings ← Pages ← Source: **GitHub Actions**.
3. ה־workflow שבקובץ `.github/workflows/deploy.yml` מריץ את הבדיקות, בונה ומפרסם בכל push.
4. פתח באייפון את הכתובת `https://<user>.github.io/<repo>/` בספארי, ואז שיתוף ← "הוסף למסך הבית".

האפליקציה משתמשת בנתיבים יחסיים, ולכן היא עובדת בכל תת־נתיב בלי שינוי הגדרות.

## מבנה
```
src/music/      Music Model — גובה צליל, MIDI, מיקום על החמשה, קווי עזר
src/notation/   Notation Renderer — VexFlow 5 עם הגופן Bravura המוטמע (אופליין)
src/audio/      Audio Engine — Web Audio, דגימות פסנתר, תזמון לפי שעון האודיו
src/engine/     Curriculum, Exercise Generator, Answer Evaluation, Hints, Stats, Achievements
src/storage/    Local Persistence — IndexedDB (Dexie). נשמרים רק ניסיונות גולמיים; כל המדדים מחושבים מהם.
src/state/      חיבור הנתונים לממשק
src/ui/         מסכים ורכיבים
```
